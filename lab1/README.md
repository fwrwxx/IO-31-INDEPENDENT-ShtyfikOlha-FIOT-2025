## 📋 Опис проєкту

Веб-застосунок для систематизації та популяризації інформації про архітектурні пам'ятки України.

## 🛠️ Технологічний стек

- **HTML5** - Семантична розмітка
- **CSS3** - Стилізація та анімації
- **JavaScript (ES6+)** - Інтерактивність
- **Tailwind CSS** (CDN) - Utility-first CSS фреймворк

## 🚀 Як запустити проєкт

### Варіант 1: Використання Live Server

1. Відкрийте папку `html-version` у Visual Studio Code
2. Встановіть розширення **Live Server**
3. Клацніть правою кнопкою миші на `index.html`
4. Виберіть **"Open with Live Server"**

### Варіант 2: Відкриття в браузері

1. Перейдіть до папки `html-version`
2. Двічі клацніть на `index.html`
3. Файл відкриється у вашому браузері за замовчуванням
