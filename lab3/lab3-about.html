1. Тема та мета роботи

Тема:

Верстка HTML-документу. Блокова верстка. Верстка засобами CSS та FLEXBOX. Адаптивна верстка. Медіа-запити. Метатег viewport.

Мета:

  • Придбати практичні навички роботи верстки сторінок засобами CSS
  • Освоїти верстку на основі Flexbox для створення адаптивних макетів
  • З'ясувати переваги та недоліки різних типів макетів веб-сторінок
  • Реалізувати адаптивний дизайн з використанням медіа-запитів

3. Семантична розмітка

Для створення структури сайту використано семантичні HTML5 елементи: 

<header>  - Шапка сайту з навігацією
<nav>     - Навігаційне меню
<main>    - Головний контент сторінки
<section> - Логічні секції контенту
<article> - Самодостатні блоки інформації
<footer>  - Нижній колонтитул з контактами

Переваги семантичної розмітки:

  • Покращена доступність для користувачів з обмеженими можливостями
  • Краще SEO-ранжування в пошукових системах
  • Зрозуміліша структура коду для розробників
  • Легше підтримувати та масштабувати проект

4. Адаптивна верстка

Сайт повністю адаптивний та коректно відображається на всіх пристроях:

Мобільні (< 768px)

  • Одноколонковий макет
  • Бургер-меню
  • Збільшені кнопки
  • Оптимізовані шрифти

Десктоп (> 768px)

  • Мультиколонковий макет
  • Повна навігація
  • Grid-системи
  • Hover-ефекти

5. Використання Flexbox

Flexbox використовується для створення гнучких макетів:

Навігаційне меню

.nav-content {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

Переваги Flexbox:

  • Проста модель розташування елементів
  • Автоматичне вирівнювання та розподіл простору
  • Легка зміна порядку елементів
  • Підтримка всіма сучасними браузерами

6. Анімації та візуальні ефекти

Використано різноманітні анімації для покращення UX:

Fade-in анімація

@keyframes fadeIn {
  from {
    opacity: 0;
    transform: translateY(20px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}
  • Плавна поява елементів при завантаженні
  • Hover-ефекти на картках та зображеннях
  • Smooth scroll до секцій
  • Анімоване бургер-меню

7. Медіа-запити

Breakpoint для мобільних

@media (max-width: 768px) {
  .nav-links {
    display: none;
  }
  .burger {
    display: block;
  }
}

Метатег viewport

<meta name="viewport" content="width=device-width, initial-scale=1.0">
