# Лабораторна робота №3 - HTML/CSS/JS версія

## Площа Ринок у Львові

Статичний веб-сайт про історичну площу Ринок у Львові, створений з використанням HTML, CSS та JavaScript.

## Структура проекту

```
lab3/
├── index.html          # Головна сторінка
├── report.html         # Сторінка звіту
├── css/
│   └── style.css       # Стилі сайту
├── js/
│   └── main.js         # JavaScript функціонал
└── images/             # Зображення
```

## Як відкрити проект

1. Відкрийте файл `index.html` у браузері
2. Для перегляду звіту відкрийте `report.html`
