1. Селектори тегу

HTML код:

<p>Це звичайний параграф з базовим стилем</p>
<h2>Заголовок другого рівня</h2>
<section>Секція з особливим оформленням</section>

CSS код:

/* Селектор тегу для параграфів */
p {
  line-height: 1.8;
  color: hsl(var(--text));
  margin-bottom: 1rem;
}

/* Селектор тегу для заголовків */
h2 {
  font-size: 2rem;
  font-weight: 700;
  color: hsl(var(--primary));
  margin-bottom: 1.5rem;
}

/* Селектор тегу для секцій */
section {
  padding: 2rem 0;
}

2. Селектори класу

HTML код:

<div class="card">
  <h3 class="card-title">Заголовок картки</h3>
  <p class="text-content">Контент картки</p>
</div>

<button class="btn btn-primary">Основна кнопка</button>
<button class="btn btn-secondary">Вторинна кнопка</button>

CSS код:

/* Базовий клас картки */
.card {
  background: hsl(var(--card));
  border-radius: 12px;
  padding: 1.5rem;
  box-shadow: 0 4px 6px rgba(0, 0, 0, 0.1);
}

.card-title {
  font-size: 1.5rem;
  font-weight: 600;
  color: hsl(var(--primary));
}

/* Класи для кнопок */
.btn {
  padding: 0.75rem 2rem;
  border-radius: 8px;
  font-weight: 600;
  transition: all 0.3s ease;
}

.btn-primary {
  background: hsl(var(--primary));
  color: white;
}

.btn-secondary {
  background: hsl(var(--secondary));
  color: hsl(var(--secondary-foreground));
}

3. Селектори ідентифікатора

HTML код:

<header id="hero">
  <h1>Унікальний заголовок</h1>
</header>

<form id="contactForm">
  <input type="text" />
</form>

<footer id="mainFooter">
  <p>Футер сторінки</p>
</footer>

CSS код:

/* Селектор ID для hero секції */
#hero {
  min-height: 400px;
  background: linear-gradient(135deg, 
    hsl(var(--primary)) 0%, 
    hsl(var(--primary-dark)) 100%);
  display: flex;
  align-items: center;
  justify-content: center;
}

/* Селектор ID для форми */
#contactForm {
  max-width: 600px;
  margin: 0 auto;
  padding: 2rem;
  background: hsl(var(--card));
}

/* Селектор ID для футера */
#mainFooter {
  background: hsl(var(--primary));
  color: white;
  padding: 2rem 0;
  text-align: center;
}

Пояснення:

ID використовується для унікальних елементів сторінки (hero, форми, футер). Кожен ID може використовуватись лише один раз на сторінці.

4. Інші селектори

Дочірні селектори (>)

/* Лише безпосередні нащадки */
.nav-content > a {
  font-weight: 600;
  color: hsl(var(--primary));
}

.card > h3 {
  margin-top: 0;
}

Сусідні селектори (+)

/* Елемент одразу після */
h2 + p {
  font-size: 1.1rem;
  color: hsl(var(--text-muted));
}

.card-title + .text-content {
  margin-top: 0.5rem;
}

Селектори атрибутів

/* За наявністю атрибута */
input[type="email"] {
  border-color: hsl(var(--primary));
}

/* За значенням атрибута */
a[href^="https://"] {
  color: hsl(var(--accent));
}

img[alt] {
  border: 2px solid hsl(var(--border));
}

Універсальний селектор (*)

/* Для всіх елементів */
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

/* У контексті */
.card * {
  transition: all 0.3s ease;
}

Висновки

У ході виконання лабораторної роботи №2 було опановано основні концепції каскадних таблиць стилів та набуто практичних навичок роботи з різними типами селекторів.

Основні досягнення:

  • Селектори: Застосовано селектори тегів, класів, ідентифікаторів, дочірні, сусідні селектори та селектори атрибутів для точного таргетування елементів.
  • Стилізація тексту: Використано різноманітні властивості для роботи зі шрифтами, розмірами, вагою, висотою рядка та декоративними елементами.
  • Кольори та фони: Створено систему кольорів на основі HSL, застосовано градієнти, напівпрозорі фони та ефект скла (glassmorphism).
  • Layout системи: Використано сучасні підходи до створення макетів за допомогою Flexbox та CSS Grid для адаптивного дизайну.
  • Анімації: Додано плавні переходи, трансформації та keyframe анімації для покращення користувацького досвіду.
  • Просунуте CSS: Застосовано CSS змінні, псевдоелементи, псевдокласи та медіа-запити для створення професійного веб-застосунку.

Створений веб-застосунок демонструє комплексне використання CSS для створення сучасного, адаптивного та естетично привабливого інтерфейсу. Усі технології інтегровані в єдину дизайн-систему, що забезпечує консистентність та підтримуваність коду.
