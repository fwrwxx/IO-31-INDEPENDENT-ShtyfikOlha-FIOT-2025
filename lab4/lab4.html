Завдання з JavaScript

Інтерактивні завдання для вивчення основ JavaScript: шаблонні рядки, керування обчисленнями, масиви та функції

Завдання #1

Чверть години

Визначення чверті години на основі введеного часу (prompt, alert, template strings)

Завдання #2

День тижня

Визначення дня тижня за номером з використанням switch-case

Завдання #3

Авторизація

Система входу для користувачів з перевіркою логіна та пароля

Завдання #4

Доставка товару

Функція розрахунку вартості доставки товару в країну (функції, параметри)

Завдання #5

Покупка дроїдів

Перевірка можливості покупки з перевіркою балансу (функції, умови)

Завдання #6

Об'єднання масивів

Створення нового масиву з обмеженням довжини (масиви, методи)
